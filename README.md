# Angular Basic E-commerce 2

Second Angular e-commerce practice project. The runnable Angular application is in `intro/createShop`; the `API` directory contains local JSON data used by the application.

## Run locally

```bash
cd intro/createShop
npm install
npm start
```

The application is served at `http://localhost:4200/`.

Do not use the sample authentication data in a production environment.

## Tech stack

- Angular 16
- TypeScript
- RxJS
- JSON Server-style local data

## Status

Learning and portfolio project.
